# Fotos de ejercicios

Pon aquí las fotos de los ejercicios. La app las carga automáticamente si el nombre del archivo
coincide exactamente con el `id` del ejercicio. Si no hay foto, se muestra el emoji de fondo.

## Formato

- **Tamaño:** 800 × 450 px (horizontal 16:9) — se recorta automáticamente
- **Formato:** `.jpg` o `.png` (preferiblemente `.jpg` para menor peso)
- **Peso máximo:** 200 KB por foto
- **Nombre:** exactamente el id del ejercicio, en minúsculas, con extensión `.jpg`

## Cómo activar una foto nueva

Después de añadir el archivo, descomenta su línea en `app/(tabs)/gym.tsx`
dentro del objeto `imageMap` de la función `getLocalImage()`.
