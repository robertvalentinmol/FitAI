# Imágenes de grupos musculares

Coloca aquí los diagramas o fotos de grupos musculares.

## Convención de nombres

```
pecho.jpg
espalda.jpg
piernas.jpg
hombros.jpg
brazos.jpg
core.jpg
cardio.jpg
```

## Tamaño recomendado

- **800 × 400 px** (banner horizontal)
- Formato: JPG o PNG
- Máximo: 300 KB por imagen

Si no hay imagen, se mostrará el emoji del grupo muscular sobre fondo de color.
